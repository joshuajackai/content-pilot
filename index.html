How to use Content Pilot

Five steps from raw transcript to a full set of ready-to-publish SEO assets.

Open Settings (the gear, top right). Choose your Content Engine (GPT-5.5, Claude Sonnet 4.6, or Gemini 3.5 Flash), paste your API key, and press Authorize System. Your key is stored only in this browser. For shared or public use, route calls through a server-side proxy.
Use the Paste tab for a transcript, the File tab to upload TXT, DOCX, or SRT, or the URL tab to pull a YouTube or Vimeo link. URL transcription needs a transcription webhook set in Settings.
Enter your target niche, then paste your links and CTAs into the boilerplate box (or use the Brand Scraper to pull them from a URL). Suggest Keywords and Extract Entities add SEO context the AI will weave into every asset.
Tick the asset types you want (Keyword Plan, YouTube Hub, SEO Titles, Viral Clips, Storyboard, and more). Optionally fine-tune the AI directives in the Advanced panel, then press Execute Full Synthesis. Each asset appears as its own card.
Use Refine on any card to adjust it in a quick chat (for example, "make it shorter" or "punchier hook"). Then Copy Asset per card, Copy All Assets, or Download .txt to take everything with you.

Before you paste a key

Keys are stored in this browser only and are sent directly to the provider from the browser. Anyone with access to this device can read them, and some providers may block browser calls (CORS). For shared or public use, route requests through a server-side proxy and use keys with spend limits.
